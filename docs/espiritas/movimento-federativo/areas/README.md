# Áreas Funcionais — Conhecimento de Domínio

> **Escopo deste diretório:** o que cada área *é* — missão, propósito, princípios,
> responsabilidades e atividades típicas. Fonte: documentos institucionais do CFN/FEB
> e das federativas estaduais.
>
> Para o recorte analítico (indicadores, KPIs, cruzamentos por região) ver
> [`docs/specs/lentes/`](../../../docs/specs/lentes/README.md).

As áreas funcionais são divisões especializadas do Sistema Federativo Espírita que orientam as atividades das casas espíritas. Cada arquivo descreve uma área com base nos documentos institucionais.
