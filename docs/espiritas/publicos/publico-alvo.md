# Geral

As análises desenvolvidas devem usar um vocabulário consistente com o público alvo, a dimensão do problema, o órgão, os projetos.

o espiritismo e não propagandista como o de "marketing" ou de uma empresa.

Em nível geral, o nível de compreensão das pessoas é básico, de uma pessoa formada profissionalmente com nível de gradução.

O interesse do público varia em função do órgão, área, e projeto trabalhado, portanto, as propostas devem ser criativas e exploratórias.



As análises devem usar as siglas espíritas, mas devem evitar siglas técnicas.
Deve existir uma seção final de glossário e referências
