Recursos: **Visões**

- Visão estadual
- Visão macro
- Visão micro
- Visão intermunicipal
- Visão municipal
- Visão Casa
- Visão por atividade

A visão é uma tela que filtra os dados pela situação geográfica deles
- a visão federativa apresenta os elementos agrupados pelo estado
- a visão macro apresenta os dados agrupados pela macro-região

pode ser qualquer das :
- mapa com eventos sinalizados
- tabela
- widgets que filtrem apenas os regionais
